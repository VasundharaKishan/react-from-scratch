# React from Scratch

Code for the 30-episode YouTube series **React from Scratch**. Each folder holds the final code from one episode.

Built with React 19 and Vite. You need Node.js installed and basic HTML, CSS and JavaScript.

## How to use

1. Create a project: `npm create vite@latest my-first-app -- --template react`
2. Open the folder for the episode you are watching and follow its README.
3. Copy its files into your project and run `npm run dev`.
