# Episode 14: Loading and Error States

Final code from this episode of React from Scratch.

The app fetches from https://jsonplaceholder.typicode.com/users, so it needs an internet connection.

## Run it

```
npm create vite@latest my-first-app -- --template react
cd my-first-app
npm install
```

Copy the files from this folder over the ones in the new project, then run `npm run dev`.
